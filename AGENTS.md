# CarePoint Hospital project rules

- This is the Bethlehem University SWER353 Web Technologies project by Mahmoud
  Abu Amria and Lour Qumsiyeh. Use English in the interface.
- Follow the assignment PDF in `docs/` when it differs from project notes. Use
  the supplied HospitalDB schema and preserve its constraints. Document any
  justified schema changes.
- Keep `frontend/` and `backend/` separate. Use plain HTML, CSS, and native
  JavaScript. Use Fetch/AJAX and JSON for asynchronous requests, and PHP sessions
  and procedural MySQLi with prepared statements for the backend. Enforce staff
  permissions on the server. The final host is InfinityFree.
- Reuse shared CarePoint styling and branding. Use navy `#142B45`, teal
  `#0D9488`, light gray `#F4F7FA`, white cards, and dark teal primary buttons.
  Build responsive layouts with visible keyboard focus, clear feedback, and
  reduced-motion support. Use the staff dashboard mockup if supplied in `docs/`.
- Use fictional data. Keep credentials out of frontend files, logs, and Git.
- Work one page at a time. Keep the code easy for both students to explain and
  use relative paths that work with Live Server on Windows and macOS. After
  each page, report the changed files and a short test checklist. Track progress
  in `README.md`.
